# Comp Suite: instaladores

Aqui ficam só os instaladores do Comp Suite (Mac e Windows), da Studio Comp.
Não tem código-fonte aqui.

- O app confere a versão nova sozinho, baixa daqui e instala.
- Cada versão é uma release. Nela vão o instalador do Mac (`.pkg`), o do Windows (`.exe`), os zips e o `latest.json`.
- `latest.json` diz a versão, o link e o SHA-256 de cada instalador. O app só instala se o SHA-256 bater.
- Versão de teste (tag com `-`, ex.: `v0.9.33-beta`) sai como pré-release e o app não oferece.

Link da versão mais nova: https://github.com/Studio-Comp/comp-suite-releases/releases/latest
